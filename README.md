# Объезд магазинов

PWA для учёта посещений магазинов Магнит и Пятёрочка: карта Орла, таймер
периодичности (по умолчанию 45 дней), дальние маршруты без карты.

Приложение работает офлайн: схема города, точки и отметки хранятся на
устройстве, а данные группы синхронизируются через Firebase Firestore.

При первом запуске приложение просит имя — им подписываются визиты и
комментарии, чтобы было видно, кто последним посетил магазин. Имя можно
изменить в настройках.

На карте есть поиск по адресу и названию магазина, переключатель офлайн-схемы
и онлайн-карты OSM, кнопка «Где я» и передача геопозиции участникам: она
работает, пока приложение открыто, и включается только после согласия.

Планировщик маршрута помогает выбрать точки на карте или через поиск,
переставить их, упорядочить по кратчайшему пути и открыть готовый порядок в
Яндекс.Картах. План хранится на устройстве.
